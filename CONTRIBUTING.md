# Contributing

Bug reports and focused pull requests are welcome.

## Development

```bash
npm install
npm test
npm run dev -- --host 0.0.0.0
```

For behavior changes, add or update tests and verify the extension in an Owlbear Rodeo room before opening a pull request.

## Reporting bugs

Please include:

- browser and operating system;
- whether you were GM or player;
- the selected tabletop item's type;
- steps to reproduce the issue;
- whether the issue occurs during zooming, panning, or both.
